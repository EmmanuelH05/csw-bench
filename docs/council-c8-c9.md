# Reasoning council — C8 and C9

Convened per the `docs/charter.md` working-style rule, on the two cases `ordering-stress-test.md`
left contested. Both readings of each case are argued at strength before a verdict. The
losing argument is recorded in full for transfer to item metadata; it is not summarised
away.

Citations are to work and named principle only. Anything requiring a page is marked
`[VERIFY: page]` and blocks ratification until checked against the physical source. No
example below is claimed as attested.

Cases considered under four possible outcomes, not two: assign per the current ordering,
assign against it, change the ordering, or exclude the case as undecidable.

---

## C8 — \*Compré los **book** ayer.

Spanish ML. NP = [los book]. The determiner is Spanish and plural; the noun is English and
unmarked. Spanish concord requires *los libros*.

### Reading A (T1) — at full strength

Number is not a peripheral feature of the Spanish DP; it is the feature the whole nominal
is built around, and it is realised by system morphemes. Under @myersscotton2000fourm,
plural is the textbook **early system morpheme**: conceptually activated with its head
noun, indirectly elected, not dependent on anything outside the head constituent. So the
element that has gone wrong here is unambiguously a system morpheme, and the System
Morpheme Principle (@myersscotton1993duelling `[VERIFY: page]`) is the prediction the item
tests. Calling this a *content* morpheme problem misdescribes what failed: *book* is a
perfectly good content morpheme doing its job of receiving a thematic role. What failed is
number concord inside an ML-framed constituent, which is system-morpheme territory.

The strongest form of the argument goes further. The reason *book* surfaces unmarked is
that English nominal morphology came along with the English noun — the noun was inserted
with its own (here, zero-realised) number specification rather than being handed the ML's.
On that construal the EL *did* supply the number morphology; it supplied it as null. The
SMP is violated because number in this DP is sourced from English, not Spanish, and the
fact that English's realisation happens to be silent is a fact about English exponence, not
about which grammar supplied the feature. `taxonomy.md` itself names "determiners and
plural marking" as the two productive T1 probes for this pair, which is an admission that
plural marking is expected to generate T1 items.

### Reading B (T5) — at full strength

T1 is not "a system morpheme went wrong." T1 is, by its own stated diagnostic, three
conjoined questions, and the third is *is it sourced from the EL?* Here there is no
EL-sourced system morpheme anywhere in the constituent. The determiner is Spanish, and it
is correct. The plural marker is not English — it is **absent**. A missing ML morpheme and
an imported EL morpheme are different objects, and the SMP as stated constrains the second.
T1's question 3 returns no, so T1 does not fire, and first-match ordering never reaches it.

T5 then fires on all four of its own questions: ML frame established; *book* is an EL
content morpheme receiving a thematic role; the ML obligatorily requires morphology on it
(plural concord, forced by *los*) which is absent; and it sits under a Spanish determiner,
so it is outside any EL island. This is the Blocking Hypothesis case
(@myersscotton1993duelling `[VERIFY: page]`) in its canonical shape: an EL content morpheme
surfacing bare where the ML obligatorily inflects. It is structurally identical to C6
(\*Yo **walk** a la escuela), which the stress test scored T5 and clean.

That identity is what defeats Reading A's null-morpheme move. If an unrealised EL number
specification counts as an EL system morpheme, then an unrealised EL tense/agreement
specification counts too, and C6 becomes T1 as well. So does every bare form in the
benchmark. T5's population goes to zero and the taxonomy ships three types, below the
`docs/charter.md` minimum of four and fatal to the `matriz` holdout design. A reading that empties
a type is not a reading, it is a redefinition, and it should be rejected on the grounds
that it is unfalsifiable: no string can distinguish "EL supplied a null plural" from "no
plural was supplied."

Reading A's appeal to the T1 probe list is a misreading of that list. Plural marking is a
valid T1 probe — for \*Compré los **books** ayer, where an English plural is physically
present inside a Spanish DP. C8 is the mirror image of that probe, not an instance of it.

### Verdict — **T5**. C8's current assignment is wrong and is reversed.

Reading B wins on the diagnostic as written, and Reading A survives only by an
unfalsifiable amendment that would empty T5.

Note what did *not* fail. The stress test recorded C8 as "the ordering's weakest point"
because "number marking sits exactly on the system/content boundary." That framing is
itself mistaken: under the 4-M model plural is not on the boundary, it is squarely an early
system morpheme. C8 was never a hard case about where the boundary sits. It was a case of
T1 being applied to a *missing ML* morpheme rather than a *present EL* one — a scope error
in application, not a defect in the ordering.

### Was the ordering wrong?

Considered and rejected. If one insisted Reading A is live, the fix on offer would be
swapping to T5-before-T1. That fix is unmotivated: T1 and T5 almost never co-fire, because
a constituent containing both an EL system morpheme and a bare EL content morpheme is
generally an EL island, which routes to T3 or to licensed. The T1/T5 ordering does very
little work in practice, so reordering it buys nothing and its consequences for the
untested cases C11–C20 are unknown. The minimal, targeted repair is a diagnostic
tightening, recorded below.

### Was exclusion right?

Rejected on decidability, but with one open risk. The item is decidable — four T5 questions,
all yes, no competing type firing. The risk is empirical rather than taxonomic: whether
*los book* is actually rejected by fluent bilinguals, or is a produced form. It cannot be
promoted to a benchmark item on the strength of this council alone; the grammaticality
judgment needs corpus support like any other. Flagged, not excluded.

### Recorded losing argument (for item metadata)

> **T1 (rejected).** Plural is an early system morpheme under the 4-M model, and number
> concord is what failed, so this is a System Morpheme Principle violation rather than a
> Blocking Hypothesis one. On the strong version, the English noun was inserted carrying
> English number specification, so number in this DP is EL-sourced and merely null-realised.
> **Rejected because** T1's diagnostic question 3 requires an EL-*sourced* morpheme and the
> plural here is absent, not English; and because the null-EL-morpheme construal is
> unfalsifiable from the string and would reclassify every bare form (including C6) as T1,
> emptying T5 and dropping the taxonomy below four types.

### What would flip this verdict

1. **The SMP's exact scope.** If @myersscotton1993duelling states the System Morpheme
   Principle such that it is violated by the *absence* of a required ML system morpheme and
   not only by the presence of an EL one, T1's scope widens and C8 becomes T1.
   `[VERIFY: page]` — this is the single citation that decides the case and must be read
   before ratification.
2. **Published 4-M treatment of null exponence.** If @myersscotton2000fourm treats an
   EL-sourced but unrealised system morpheme as within the model's scope, Reading A's strong
   version stops being unfalsifiable. `[VERIFY: page]`
3. **A separate type for concord failure.** If the project adds a type for
   bare-form-under-obligatory-concord distinct from bare-form-under-obligatory-inflection,
   C8 moves there and T5 narrows. This would need its own populability argument.
4. **Corpus evidence that *los book* is produced systematically** by fluent bilinguals,
   which would move the item from the violation set to excluded or to a licensed contrast.

### Consequence the council flags beyond the verdict

C8's repair set is where MLF gets tested rather than applied. The two candidate repairs are
*los libros* and *los books*. The second is a Spanish DP containing an English plural — a
T1 configuration under a strict reading of the SMP, yet doubled or EL-retained plural
marking is discussed in the MLF literature as an attested outcome rather than a violation
(@myersscotton2002contact `[VERIFY: page]`). If *los books* is both natural and SMP-violating,
that is a tension in the theory the benchmark should surface as a finding, not paper over
in a gold label. Recommend the C8 item's gold repair be *los libros* only, with *los books*
scored as a flagged near-miss rather than a failure, and the tension named in
`limitations.md`.

## C9 — \*Es **Juan's** casa.

Spanish ML. Constituent = [Juan's casa]. English possessive clitic, Spanish head noun.
Spanish requires *la casa de Juan*.

### Reading A (T1, the intuition) — at full strength

Strip the sentence to what is foreign and exactly one thing remains: the clitic *-s*.
*Juan* is language-neutral in form, *casa* is Spanish, *Es* is Spanish. A single English
morpheme entered a Spanish frame, and it is a system morpheme, not a content morpheme — it
assigns no thematic role. That is the System Morpheme Principle violated in its purest
possible form, with no confound.

The order change is not an independent fact about the utterance. It is entailed. English
*'s* is a prenominal genitive; there is no way to import it and leave Spanish order intact.
So describing C9 as an order violation names the symptom and drops the cause. Worse, it
makes the two types non-independent in a way that damages the downstream holdout: if T2
contains both C5-type items (order displaced under general EL pressure) and C9-type items
(order displaced as a mechanical consequence of one imported morpheme), then holding out T2
in `matriz` holds out two different constraints under one label, and a model that learned
one and not the other is scored as if the label were coherent. Mutual exclusivity at the
label level is worth nothing if the label is not mechanistically coherent.

There is also a simple fairness point about the repair task. Asked to repair C9 minimally,
the correct edit is to remove an English morpheme and restore the *de*-phrase. A model that
locates the violation at *-s* has located it correctly. Grading it against a T2 gold label
tells us the model failed at order when it succeeded at morphology.

### Reading B (T2, the current assignment) — at full strength

Two independent defences, and the second is the decisive one.

**First: the ordering is not a causal ordering, and cannot be.** Nothing in `taxonomy.md`
ranks types by etiology, and nothing could. "Which violation caused the other" is not
recoverable from a string. Two annotators can look at *Juan's casa* and agree that Spanish
requires postnominal *de* and this is prenominal; they cannot be relied on to agree about
which of two co-present violations is ontologically prior. The ordering exists to make
annotation determinate, and it is justified in the document on a stated structural ground:
constituent order determines which elements are even *in* the constituent under evaluation,
so it is settled first. Reading A asks the taxonomy to encode a causal story it deliberately
does not encode, and the price of granting that request is inter-annotator disagreement on
every overlap case, which is precisely the failure mode the ordering was built against.

T2's own diagnostic returns four clean yeses here, note — this is not assignment by
elimination. ML frame established. EL material present in the constituent, so the C4 scope
hole does not reopen. Surface order does not match ML requirement. And the deviation is not
a licensed ML alternative: Spanish has no prenominal genitive construction at all, so
question 4 — the question `taxonomy.md` warns is where T2 is most often misapplied — passes
on the strongest possible grounds. C9 is a better T2 item than C5 is.

**Second, and decisive: T1 cannot take this morpheme.** T1 is restricted by its own
diagnostic question 2 to **early** system morphemes. English possessive *'s* is not early.
It is a **late bridge** system morpheme — structurally assigned within a maximal projection,
integrating possessor with possessum, in the same class as English *of*
(@myersscotton2000fourm `[VERIFY: page]`). It is not conceptually activated with a head; it
is structurally required by the configuration it appears in. Compare the genuinely early
possessive: the determiner *su*/*my*, which is elected with its head. C9 has the clitic, not
the determiner.

`taxonomy.md`'s own 4-M table makes this explicit: late bridge is listed with "Used by: —".
No shipped type takes bridge morphemes. So the intuition that C9 "is really T1" is not a
close call the ordering overrode — it is a type error. T1 was never available.

### Verdict — **T2**. The current assignment stands; its stated reasoning does not.

The stress test recorded C9 as "counterintuitive," implying the ordering overrode a correct
intuition for procedural reasons. That is not what happened. T2 is the only shipped type
whose diagnostic C9 satisfies, because *'s* is a bridge morpheme and T1 is restricted to
early ones. The verdict was right by accident and should now be right on the record.

This also means the ordering was never load-bearing for C9. Under the corrected 4-M
classification only one type fires, so the T2-before-T1 rank never had to adjudicate
anything. C9 is therefore not evidence for the ordering either, and should be removed from
the column of cases the ordering is said to have resolved.

### Was the ordering wrong?

No — and C9 turns out to supply no evidence about it in either direction. Reading A's real
complaint is not about rank order; it is that the taxonomy has no type for an EL bridge
morpheme. That complaint is correct, and reordering T1 above T2 would not fix it. It would
only relabel C9 with a type whose diagnostic C9 fails.

### Was exclusion right?

Rejected, narrowly. The case for exclusion is that assigning T2 records order as the
construct under test when the item's only foreign material is a morpheme, so the item
arguably measures the wrong thing — the same species of objection that removed C4. The case
against, which wins: C4 was out of scope because it contained no EL material at all and so
could not test an MLF constraint. C9 contains EL material and satisfies a shipped
diagnostic positively rather than residually. It measures a real constraint. It merely fails
to measure the *most specific* constraint it violates, and that is a gap in the taxonomy's
coverage, not a defect in the item.

### Recorded losing argument (for item metadata)

> **T1 (rejected).** The only foreign element is the possessive clitic; the order change is
> mechanically entailed by importing it, so T2 names the symptom and drops the cause.
> Assigning C9 to T2 also makes T2 mechanistically heterogeneous, which weakens the
> downstream holdout, and mis-scores a repair that correctly locates the violation at *-s*.
> **Rejected because** English possessive *'s* is a late *bridge* system morpheme, not an
> early one, and T1's diagnostic admits only early system morphemes — so T1 was never
> available regardless of ordering. Secondarily, the ordering is procedural and structural,
> not causal, and MLF's types are not ranked by etiology anywhere in the taxonomy.
>
> The rejection is contingent on the 4-M classification of *'s*, which is
> `[VERIFY: page]` in @myersscotton2000fourm and is the one citation that could revive this
> reading.

### What would flip this verdict

1. **The 4-M status of possessive *'s*.** If @myersscotton2000fourm classifies it as early
   rather than late bridge, T1 becomes available, the case becomes a genuine T1/T2 overlap,
   and the ordering — not a type error — decides it. The verdict would probably still be T2
   on ordering grounds, but Reading A would go from inadmissible to merely outranked, and
   the metadata note must change accordingly. `[VERIFY: page]`
2. **Adding a bridge-morpheme type.** If the taxonomy grows a type for EL late bridge
   morphemes, C9 must be re-adjudicated, and where that type ranks relative to T2 becomes a
   new open question needing its own stress cases.
3. **A Spanish variety licensing prenominal genitives with proper names.** That would fail
   T2's question 4 and move C9 to licensed or excluded. The council knows of no such
   variety and does not assert its non-existence.

## The gap C9 exposed, which is larger than C9

Folding T4 into T1 removed the outsider type. Bridge was never used. The shipped taxonomy
therefore has **no type for any EL-sourced late system morpheme**, of either kind.

C9 conceals this because its bridge morpheme happens to drag order with it, so T2 catches
it. Strip that coincidence and nothing catches it. Consider a case the stress test does not
contain:

> \*el libro **of** Juan

English *of* is a late bridge system morpheme sourced from the EL, inside a Spanish frame.
T3 does not fire — no island. T2 does not fire — N + PP is exactly Spanish order, so the
diagnostic's question 3 returns "order matches." T1 does not fire — *of* is not early. T5
does not fire — *of* is not a content morpheme. **No type.**

The taxonomy silently declines to classify a violation it is committed to predicting. This
is a coverage hole, not an ordering defect, and it was invisible until C9 forced the 4-M
status of *'s* to be settled. The council makes no change outside this file, but records
three options for whoever ratifies:

1. **Add a bridge type.** Restores coverage, restores part of what folding T4 cost, and
   costs a new populability argument that English's small closed class of bridge morphemes
   (*of*, *'s*) may not survive — the same argument that killed T4.
2. **Widen T1 from "early system morpheme" to "EL system morpheme."** Cheap, coherent with
   T4 having already been folded in on similar grounds, and it makes T1 the general
   SMP type. The cost is the one `taxonomy.md` calls "the single most load-bearing decision
   in this document": the early/late split is what makes MLF's predictions graded rather
   than binary, and this abandons the last of it. It would also make Reading A of C9 correct
   and require C9 to be re-decided on ordering.
3. **Document the hole and exclude bridge-only items,** reporting the excluded count as the
   statistic `design.md` already provides for. Honest, cheapest, and loses real coverage.

The council's own preference is (2) with the loss recorded in `limitations.md`, on the
grounds that T1 has already absorbed T4 for populability reasons and a type defined as "EL
system morpheme in an ML frame" is both simpler to annotate and closer to how the System
Morpheme Principle is actually stated. But this is a taxonomy-level decision outside the two
cases remitted here, and it should not be taken as settled by a council convened on C8 and
C9.

## Actions this council produces

Recorded here only; no other file is edited by this council.

1. **C8 is reassigned T1 → T5.** `ordering-stress-test.md` results table and the C8
   narrative are wrong as written, as is `taxonomy.md`'s summary of C8 as a system/content
   boundary case.
2. **T1's diagnostic needs one clarifying sentence:** question 3 requires an EL-sourced
   morpheme that is *present*; a missing or unrealised ML system morpheme is never T1. This
   is the repair C8 actually calls for, in place of any ordering change.
3. **C9 keeps T2, with its reasoning replaced.** The recorded ground is that *'s* is a late
   bridge morpheme and T1 admits only early ones — not that the ordering overrode a correct
   intuition. C9 should also be removed from the set of cases cited as evidence that the
   ordering works, since under the corrected classification only one type ever fired.
4. **\*el libro of Juan should be added to the stress test** as part of the expansion to
   twenty, as the minimal case isolating the bridge-morpheme hole.
5. **Two `[VERIFY: page]` items now block ratification specifically:** the SMP's wording in
   @myersscotton1993duelling (decides C8) and the 4-M classification of possessive *'s* in
   @myersscotton2000fourm (decides C9's reasoning and possibly its verdict). Neither case is
   ratified until both are read.
6. **Neither case forces a change to the first-match ordering** T3 → T2 → T1 → T5. Both
   turned on type *scope*, not type *rank*.
